Portfolio:

To see all of my work, check out my GitHub or my itch.io!

ALL OR NOTHING:

Currently working on an original indie fighting game in the IKEMEN-GO engine. What originally started out as a small project for the Fighting Game Jam turned into a full-featured game. Come see our progress!

Jack in the Box:

Rage platformer made in Unity as a final project for UVA Game Design course. Me and a small team created a full game design document, prototyped out game mechanics, and then build the whole thing out over a month. Come try out the levels and see how many you can beat!

ML4VA:

Achieved 3rd place in the ML4VA Machine learning competition by training an XGBoost algorithm based off of public Virginia testing data to predict Virginia K-12 State Assessment pass rates based on various socioeconomic factors. To do this, we cleaned a public Kaggle dataset and trained various different kinds of models until we found XGBoost to be most effective, achieving an R-Squared score of 0.7683. See the source code here!

Strega:

Short Spooky Halloween game jam project I did with the local RVA Game Jams group. I was a scripter and helped design the levels and implemented the Donkey Kong inspired section. This was one of my first real in-person game jams and was a great experience. Complete the ritual before it is too late!

ShadowBox:

Created a mouse training game in Unity to help drill common mouse movements found in competitive Real-Time-Strategy games. This was a Summer project between my freshman and sophomore year when I barely knew how to code, and LLMs hadn't even gone public yet. Was just me, YouTube tutorials, and way too much free time. Let's train those mouse skills!
